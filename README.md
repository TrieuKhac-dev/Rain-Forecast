# Rain Forecast

Dự án dự báo mưa cho các quận trong thành phố Hồ Chí Minh.

## Mục tiêu

Xây dựng mô hình dự báo lượng mưa trong thành phố, phục vụ công tác quản lý đô thị, cảnh báo ngập và hỗ trợ người dân.

## Trạng thái dự án

- Giai đoạn: EDA + data cleaning
- Chưa có code huấn luyện
- Chưa có thử nghiệm
- Chưa chọn model cuối cùng

## Phạm vi hiện tại

- Thiết lập môi trường làm việc
- Xác định bài toán dự báo mưa theo quận
- Chuẩn bị nền tảng cho bước chọn baseline model và chạy thử nghiệm đầu tiên
